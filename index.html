// our take on ai

The model is the smallest part of the system.

Every coding agent markets the model. We think that's the wrong bet — models are stochastic and occasionally wrong no matter how capable they get. Adventurers Harness spends its engineering budget on the other side of the equation: deterministic gates that catch what the model gets wrong, every single time.

1–10% Model inference — proposes the change, nothing more.
90–99% Deterministic pipeline — syntax, compilation, sandboxing, diff and memory checks that certify it's actually correct before disk commits.
❯# a smarter model doesn't need fewer gates. it still gets all 6.
// deterministic pipeline

Deterministic 6-Gate Certification Pipeline

The model never decides completion. Every code suggestion must pass 6 non-bypassable preflight gates before disk commits.

01 🧩
SyntaxGate

Extracts markdown code blocks and validates bracket, brace, and parenthesis parity with AST tokenization.

02 🔁
RepeatGate

Intercepts hallucination loops and duplicate turn submissions via cryptographic MD5 turn hashing.

03 ⚙️
CompilationGate

Performs non-destructive Swift/Clang type-checking in isolated memory buffers prior to writing changes.

04 🛡️
DiffGate

Inspects command risks, blocking destructive commands (rm -rf, sudo, git push -f) and fencing secrets.

05 🧠
MemoryGate

POSIX getrusage resident memory monitor bounding task memory and preventing OOM leaks.

06 🎯
ObjectiveGate

Validates immutable task contract completion, keyword satisfaction, and budget consumption limits.
